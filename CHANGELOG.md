### Added

- Initial repository foundation with MIT license, editor configuration, and environment template.
- FastAPI service scaffold in `apps/api` with typed Pydantic settings, CORS configuration, and `/health` endpoint.
- React, TypeScript, Vite, and Tailwind CSS frontend scaffold in `apps/web` with `pt-BR` and `en` i18n and Riot Games legal footer.
- GitHub Actions CI workflow for linting, type checking, unit tests, and production frontend build.
- Initial architecture documentation, legal compliance checklist, and Architecture Decision Records (`docs/adr/`).
